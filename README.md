# stemsampler-pro
 StemSampler Pro v1.0 — Plugin Audio VST3  Séparez les stems (voix, basse, drums, other) et samplez en temps réel.  🔧 Fonctionnalités : - Séparation de stems en temps réel - Sampler avec stretch, repitch, enveloppe - Effets intégrés : delay, reverb, distortion, phaser, vinyl, stutter - EQ 4 bandes + compresseur - Compatible tout DAW VST3
